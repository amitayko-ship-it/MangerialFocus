מעולה.

# Flow סופי (Execution, ללא סוכן)

נקודת מוצא:
✔ יש אבן גדולה
✔ יש 3 פרקטיקות

```
Stakeholders → 30 Day Plan → Keystone → Success → Calendar Sync
```

# מסך 1 — Stakeholders (Alignment)

## 🎯 מטרה

לזהות מי צריך לזוז יחד איתי + להוציא בקשה בפועל.

לא CRM.
לא ניהול קשרים.
רק פעולה אחת: **לבקש**.

---

## Header

מי צריך להיות איתך ב־30 הימים הקרובים?

---

## קומפוננטות

### ➕ Add Person (chips)

שדה מהיר:
הקלד שם + Enter

---

### 🧩 Card לכל אדם

| שדה  | סוג                      |
| ---- | ------------------------ |
| Name | טקסט                     |
| Role | Partner / Approver / FYI |
| Ask  | טקסט קצר (max 50 תווים)  |

דוגמה:
"חצי שעה שבועית לסקירה"

---

### ✉️ Message Generator (מעודכן לפי הבקשה שלך)

כפתור:
צור הודעה

בלחיצה:
נפתח Drawer/Modal עם:

טקסט מוכן + כפתור Copy

נוסח קבוע (קצר, ניטרלי, משפט אחד):

"היי [שם], אני בפוקוס של 30 יום על [האבן]. אשמח לבקש ממך [Ask] באופן קבוע. מתאים?"

אפשרויות:
[Copy]  [Edit]  [Close]

❗ אין שליחה אוטומטית
❗ המשתמש שולח עצמאית

---

### ✅ Status

Checkbox:
☐ ביקשתי
☐ קיבלתי אישור

(שני מצבים בלבד, בלי היסטוריה)

---

## Data Output

```json
stakeholders: [
  { "name": "רז", "role": "partner", "ask": "חצי שעה שבועית", "status": "asked" }
]
```

## חלק א — תדירות (פשוט, עם Defaults חכמים)

לכל פרקטיקה:

| שדה         | UX                  |
| ----------- | ------------------- |
| פעמים בשבוע | 1–7 selector        |
| משך         | 15 / 30 / 45 / 60   |
| חלון זמן    | בוקר / צהריים / ערב |

❗ לא בחירת ימים ידנית כברירת מחדל
המערכת תציע אוטומטית פיזור

---

## ⚡ Energy Meter (מעודכן)

חישוב:
סך דקות שבועיות

תצוגה:

* ירוק → עד 20% זמן פנוי
* כתום → 20–35%
* אדום → 35%+

טקסט ניטרלי:
"עומס שבועי: 4.5 שעות"

❗ אין שיפוט / אין הטפה

---

## חלק ב — Auto Schedule

* מפזרת בלוקים אוטומטית
* יוצרת Calendar view
* מאפשרת Drag & Drop

המשתמש רק מזיז.

# מסך 3 — Keystone & Success

## 🎯 מטרה

לנעול הרגל פתיחה + מדד הצלחה

---

## Keystone Habit

שדות:

"זה יקרה מיד אחרי ש…"
Dropdown:

* הקפה הראשון
* פתיחת מחשב
* הגעה למשרד
* סוף יום
* מותאם אישית

"אני אבצע:"
טקסט קצר

משך:
5 דקות (קבוע)

---

## Success Metric

שדה קצר:

מה ייחשב הצלחה מדידה בעוד 30 יום?

(משפט אחד בלבד)

דוגמה:
"3 פגישות מכירה נסגרו"

# הארכיטקטורה הסופית (ברורה לפיתוח)

| שלב          | כלי | אחריות           |
| ------------ | --- | ---------------- |
| Discovery    | AI  | אבנים + פרקטיקות |
| Stakeholders | UI  | יישור אנשים      |
| Planning     | UI  | שיבוץ זמן        |
| Keystone     | UI  | הרגל יומי        |
| Calendar     | API | סנכרון           |

AI לא נוגע בביצוע.
הביצוע 100% deterministic.

# למה זו גרסה נכונה יותר

* אין תלות בוואטסאפ
* אין אוטומציות חודרניות
* פחות חיכוך
* פחות החלטות
* יותר copy → send → done
* פחות “מוצר מורכב”, יותר “כלי עבודה”
